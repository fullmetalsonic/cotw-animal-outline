COTW Animal Outline v0.4.3

Latest stable release:
https://github.com/fullmetalsonic/cotw-animal-outline/releases/latest

QUICK START
1. Extract the ZIP and run COTWAnimalOutline.exe. Python is not required; a standalone EXE is also available.
2. To replace an existing copy, close its program before running the new EXE.
3. Start the game and enter a single-player reserve.
4. Turn on only the modes you want. All six start OFF.

Supported: Windows 10/11 x64, Steam build 26051119 / code 3366163.
The app finds the install path from the running game process; it does not edit
game files, saves, or Steam launch options.

MODES
Live outline: white or blue, loaded animals only; no auto-spotting.
Carcass outline: orange (#FF5900), loaded carcasses only.
Ninja: blocks AI hearing/vision of player/ATV movement and player scent detection.
OFF restores native calculations. Scent-eliminator supplies/timers and wind stay
unchanged. The new scent filter has not been verified in the running game.
Keep Dog Outline: preserve the game's native pet outline while clues are hidden.
Hellhound: Retriever dog required. Class 1 keeps native behavior; classes 2–9
follow the dog's mouth and drag along the ground. Terrain contacts remain;
other carcass contacts are excluded only during transport. Arrival, cancellation
and OFF release the body for E-harvest. The user confirmed class 5 transport to
the end and opening the normal E-harvest screen; this does not cover every class
or obstacle condition.
Silencer: all weapons use longbow firing and bow impact audio, with the native
longbow AI sound profile. No ballistics, damage, ammunition, or reload changes.
Separate rifle/revolver/shotgun tails are suppressed while Silencer is ON.
The user verified bow firing/impact sounds and original reload audio on an AR15 .300.
Other weapons and actual animal hearing remain untested in gameplay. A reported
compound-bow sound during later actions predates Silencer and remains unresolved.

ALL ON/OFF are at the top. Ctrl+Shift+F10 toggles all modes; any ON turns all
OFF, and all OFF turns all ON. No F1 shortcut. UI language follows the Windows
display language: Korean for Korean, English otherwise (region is independent).
See README.md and VALIDATION.md for details and limits.
