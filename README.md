# COTW Animal Outline

theHunter: Call of the Wild의 **사냥감 윤곽 표시만** 파랑 또는 흰색으로 유지하는 Windows용 실험 모드입니다. 직접 발견하지 않은 사냥감과 새로 로드되는 사냥감에도 기존 윤곽 효과를 적용합니다. 실제 탐지 키, 발견 알림, 동물 정보 공개 또는 탐지 기록을 자동으로 발생시키지 않습니다.

> **실험용 v0.1.0:** 실제 엔진의 모델 상태와 코드 검사는 통과했습니다. 장애물 뒤 가시성과 최종 화면 품질은 아직 플레이로 검증하지 않았습니다. 완성된 화면 효과를 보증하는 배포본은 아닙니다.

## 간단한 실행

1. [최신 배포](https://github.com/fullmetalsonic/cotw-animal-outline/releases/latest)에서 Windows ZIP을 받아 아무 폴더에 압축을 풉니다.
2. `COTWAnimalOutline.exe`를 실행합니다. **Python 설치나 게임 폴더로 파일 복사는 필요 없습니다.**
3. 게임을 실행하고 싱글플레이 사냥터에 들어갑니다.
4. 모드 창에서 **파랑 / 흰색**을 선택하고 **모드 ON**을 누릅니다.

**설치 위치 자동 감지:** 실행 중인 게임의 실제 실행 파일 경로를 Windows에서 조회하므로, Steam 라이브러리가 C:·D:·다른 드라이브에 있거나 경로에 공백·한글이 있어도 직접 지정할 필요가 없습니다. 모드 실행 파일도 게임 밖의 폴더에 둘 수 있습니다.

`모드 OFF` 또는 모드 창 종료로 갱신을 멈춥니다. 게임이 진행 중이면 임시 윤곽은 짧은 유지 시간과 페이드 후 해제됩니다. 색상 변경은 OFF에서 합니다. 게임 파일·세이브 파일·Steam 실행 옵션을 직접 수정하지 않습니다. 제거하려면 모드를 닫고 내려받은 폴더를 삭제하면 됩니다.

## 지원 범위

- Windows 10/11 x64, Steam build **26051119**, game code **3366163**.
- 검증된 실행 파일 SHA-256: `33c8306e52c5541a5b87e4af576f4149f3da0c23b36775372ec6c41adbab73ca`.
- 게임 위치와 별개로 **파일 해시·실행 코드 패턴 검사**를 통과해야 합니다. 다른 빌드에서는 쓰기 없이 중단합니다. Epic 등 다른 실행 파일의 호환성은 검증하지 않았습니다.
- 현재 게임이 로드한 야생동물 모델이 대상입니다. 렌더링 거리 밖의 동물을 추가로 로드하거나 생성하지 않습니다. 반려견은 제외합니다.
- 싱글플레이에서 검증했습니다. 멀티플레이 사용·전 동물 종·전 맵·장시간 플레이는 검증하지 않았습니다.
- ON 동안 기존 발견 윤곽의 색과 유지 시간도 임시 값으로 갱신됩니다. OFF 후 다시 발견하면 게임의 기본 발견 표시를 사용합니다.
- 외부 프로세스의 모델 수명 변화와 쓰기 사이의 경쟁 가능성을 완전히 제거한 내부 플러그인은 아닙니다. 개별 대상이 해제되면 그 대상을 건너뛰고, 버전·사냥터·쓰기 오류는 전체 OFF 처리합니다.

## 확인된 결과와 남은 확인

기존 핵심 구현의 실제 게임 프로세스 로그에서 양색상 모두 최대 **27개 모델**의 윤곽 플래그·색상 활성화와 OFF 해제를 확인했습니다. 파랑은 새 대상 3건, 흰색은 새 대상 1건에도 반영됐으며 실제 탐지 목록은 바뀌지 않았습니다.

배포 준비에서 설치 경로 감지와 업데이트 확인, 패키지 실행을 별도로 검사합니다. 드라이브·공백·한글 경로는 모의 Windows API 검사로 확인하며, 다른 드라이브의 실제 게임을 다시 설치해 실행한 검사는 아닙니다. 최종 화면의 가림 처리와 가시성은 미확인입니다. 공개용 요약은 [VALIDATION.md](VALIDATION.md)를 참조하세요. 게임 원본·세이브·개인 로그·스크린샷은 포함하지 않습니다.

## 소스 실행·빌드

실행 파일 사용에는 별도 런타임이 필요 없습니다. 소스는 Python 3.12 x64와 Tkinter를 사용합니다.

```powershell
python outline_mod.py
python outline_mod.py --self-test
python -m unittest discover -v
.\build.ps1
```

빌드는 프로젝트 전용 가상 환경과 고정된 빌드 의존성을 사용합니다. 실행에 필요한 제3자 라이선스 고지는 ZIP과 실행 파일 안에 포함됩니다.
