COTW 사냥감 윤곽 모드 0.2.0 (실험 모드, Windows x64)

이 안내는 네 기능을 포함한 v0.2.0 기준입니다. 배포: https://github.com/fullmetalsonic/cotw-animal-outline/releases/latest

1. 준비된 Windows ZIP을 원하는 폴더에 압축 풉니다.
2. COTWAnimalOutline.exe를 실행합니다. Python 설치나 게임 폴더 복사는 필요 없습니다.
3. 게임을 실행하고 싱글플레이 사냥터에 들어갑니다. 게임을 먼저 실행해도 됩니다.
4. 창에서 생체·사체 윤곽, 닌자, 반려견 윤곽 유지를 각각 선택해 필요한 것만 켭니다. 모든 모드는 기본 OFF입니다.

생체: 흰색 또는 파랑을 선택합니다. 2026-10-29 사용자가 두 색 모두 실제 플레이에서 표시되는 것을 확인했습니다.
사체: 생체와 별도 색상 선택기 및 ON/OFF가 있습니다. 기본색은 주황 #FF5900입니다. 아직 로드되지 않은 사체는 보이지 않고, 모델이 로드되면 적용됩니다. 실제 사체 관찰과 나무·지형 뒤 가시성은 확인된 장면에 한정됩니다.
반려견 윤곽 유지: 전체 동물 흔적을 숨겨도 반려견 윤곽만 원래 게임의 켜기·색상·가림 설정대로 표시합니다. 닌자의 반려견 감지 차단은 그대로 유지합니다. 이 기능을 꺼도 전체 흔적 숨김 설정은 바뀌지 않습니다.
닌자: ON일 때 플레이어 걷기/달리기와 현재 탑승 ATV의 이동 소음 및 모습에 대한 AI 감지를 함께 차단합니다. OFF를 누르면 두 감지 모두 원래 계산으로 돌아갑니다. 플레이어에게 들리는 엔진·주행음과 발소리, 소음 게이지·냄새·발포 감지는 유지됩니다. 검증 범위는 VALIDATION.md에 기록합니다.
우측 아래 소음계와 눈 모양은 기본 HUD 표시를 유지하므로 닌자 ON이어도 남습니다. 동물 AI의 실제 감지 계산과 별도입니다.
승하차 중에는 ON 선택을 유지하며 '상태 전환 대기'로 표시할 수 있습니다. 연결을 다시 검증하면 자동 재적용합니다. 다른 윤곽 모드의 선택은 유지합니다.

게임 설치 위치는 실행 중인 프로세스에서 자동 조회됩니다. 다른 드라이브, 공백, 한글 경로도 직접 지정할 필요가 없습니다. 파일·세이브·Steam 실행 옵션은 편집하지 않습니다.

끄고 싶은 기능의 OFF를 누르세요. 창을 닫으면 모든 갱신을 멈추고 게임 진행 중 잠시 후 임시 효과가 해제됩니다. 활성 모드의 강제 종료 시험은 수행하지 않았습니다.
