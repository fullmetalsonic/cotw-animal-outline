COTW 게임 모드 v0.4.3

1. ZIP을 내려받습니다. 기존 버전을 교체할 때는 실행 중인 프로그램을 먼저 닫고 압축을 푼 뒤 새 COTWAnimalOutline.exe를 실행하세요. 단독 EXE도 제공됩니다.
2. 게임에서 싱글플레이 사냥터에 들어간 뒤 필요한 기능을 켜세요.
3. 위쪽 전체 ON / 전체 OFF로 여섯 기능을 함께 조작할 수 있습니다.
4. Ctrl+Shift+F10은 하나라도 켜져 있으면 모두 끄고, 모두 꺼져 있으면 모두 켭니다.
5. 창을 닫으면 모드 갱신을 중지하고 임시 후크를 복원합니다. 재실행 시 모두 OFF입니다.

설치 위치는 실행 중인 게임 프로세스에서 자동으로 찾습니다. 게임 폴더 복사, Python 설치, 세이브·Steam 옵션 변경은 필요 없습니다.
Windows 표시 언어가 한국어면 한국어, 그 외에는 영어로 실행합니다. 국가·지역 설정과 무관합니다.

생체 윤곽: 흰색/파랑. 실제 탐지나 동물 정보 공개 없이 현재 로드된 야생동물을 표시합니다.
사체 윤곽: 별도 색상/ON/OFF. 기본 주황 #FF5900. 아직 로드되지 않은 먼 모델은 표시되지 않습니다.
반려견 윤곽: 전체 흔적을 숨겨도 게임의 사냥개 윤곽 설정대로 표시를 유지합니다.
닌자: 이동·ATV 소음과 모습, 플레이어 냄새의 AI 감지를 함께 차단합니다. OFF면 원래 계산으로 돌아옵니다. 효과음·소음계·탈취제 수량/시간·바람과 별도 발포 경로는 유지합니다. 새 무취 기능의 실제 동물 반응은 아직 미확인입니다.
헬하운드: 리트리버 DLC/회수 직업이 필요합니다. 1급은 기존 회수, 2~9급은 죽은 사체가 개의 입을 따라 지면에 끌려옵니다. 운반 중 사체만 장애물을 통과하고 지면 접촉을 유지합니다. 도착·취소·OFF 때 내려놓으며 E로 수확합니다. 실제 등급·질량·보상은 바꾸지 않습니다. 사용자는 5급 사체를 끝까지 가져온 뒤 일반 E 수확 화면이 열린 것을 확인했습니다. 모든 등급·장애물 조건을 확인한 것은 아닙니다.
소음기: 모든 무기의 발사음은 롱보우, 탄착음은 활 소리로 바꾸고 총기 발사 반향 3종을 차단합니다. AI 계산도 롱보우 기준으로 처리합니다. 탄도·피해·탄약·장전 소리는 유지합니다. AR15 .300에서 발사·탄착은 활 소리, 장전은 원래 소리인 것을 사용자가 확인했습니다. 다른 무기별 청취와 실제 동물 반응은 아직 미확인입니다. 소음기 추가 전부터 보고된 장비 교체·후속 행동 중 컴파운드 활 소리 재생은 원인 미해결이며 이번 수정의 해결 범위가 아닙니다.

각 모드는 독립 ON/OFF입니다. 반려견/리트리버가 없으면 해당 기능은 연결을 기다립니다.
소음기 OFF 후 새로 시작하는 소리는 원래 소리로 돌아갑니다.
단축키가 다른 프로그램과 충돌하면 전체 ON/OFF 버튼을 사용하세요.

지원: Windows 10/11 x64, Steam build 26051119 / game code 3366163. 다른 게임 버전은 동작을 중단합니다.
