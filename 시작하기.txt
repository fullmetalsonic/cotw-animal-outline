COTW 사냥감 윤곽 모드 0.3.0 (정식 안정판, Windows x64)

배포: https://github.com/fullmetalsonic/cotw-animal-outline/releases/latest

1. 최신 정식 Windows ZIP을 원하는 폴더에 압축 풉니다.
2. COTWAnimalOutline.exe를 실행합니다. Python 설치나 게임 폴더 복사는 필요 없습니다.
3. 게임을 실행하고 싱글플레이 사냥터에 들어갑니다. 게임을 먼저 실행해도 됩니다.
4. 창에서 생체·사체 윤곽, 닌자, 반려견 윤곽 유지, Hellhound를 각각 선택합니다. 모든 모드는 앱을 다시 실행하면 기본 OFF입니다.

생체: 흰색 또는 파랑을 선택합니다. 2026-10-29 사용자가 두 색 모두 실제 플레이에서 표시되는 것을 확인했습니다.
사체: 생체와 별도 색상 선택기 및 ON/OFF가 있습니다. 기본색은 주황 #FF5900입니다. 아직 로드되지 않은 사체는 보이지 않고, 모델이 로드되면 적용됩니다. 실제 사체 관찰과 나무·지형 뒤 가시성은 확인된 장면에 한정됩니다.
반려견 윤곽 유지: 전체 동물 흔적을 숨겨도 반려견 윤곽만 원래 게임의 켜기·색상·가림 설정대로 표시합니다. 닌자의 반려견 감지 차단은 그대로 유지합니다.
닌자: ON일 때 플레이어 걷기/달리기와 현재 탑승 ATV의 이동 소음 및 모습에 대한 AI 감지를 함께 차단합니다. OFF를 누르면 원래 계산으로 돌아갑니다. 플레이어에게 들리는 엔진·주행음과 발소리, 소음 게이지·냄새·발포 감지는 유지됩니다. 검증 범위는 VALIDATION.md에 기록합니다.
Hellhound: 게임에서 Retriever 직업을 가진 반려견이 필요합니다. Hellhound 모드를 직접 ON으로 켜면 1급은 원래 회수 동작을 유지하고, 2~9급 사체는 원래 회수 명령으로 플레이어 앞에 이동합니다. 사체가 놓인 뒤 E를 눌러 일반 수확/트로피 화면을 직접 엽니다. 자동 수확하지 않으며 소유권 규칙을 우회하지 않습니다. 자연스러운 입 물기·운반·투하 동작은 제공하지 않습니다. 게임의 기존 이동·중량 계산을 유지합니다. 실제 게임 확인은 2급과 3급에 한정됩니다.

게임 설치 위치는 실행 중인 프로세스에서 자동 조회됩니다. 다른 드라이브, 공백, 한글 경로도 직접 지정할 필요가 없습니다. 파일·세이브·Steam 실행 옵션은 편집하지 않습니다.

끄고 싶은 기능의 OFF를 누르세요. 창을 닫으면 모든 갱신을 멈추고 게임 진행 중 잠시 후 임시 효과가 해제됩니다. 활성 모드의 강제 종료 시험은 수행하지 않았습니다.
