# COTW 게임 모드

theHunter: Call of the Wild 싱글플레이용 Windows 모드입니다. 게임 설치 위치를 실행 중인 프로세스에서 자동으로 찾습니다. **[최신 배포 다운로드](https://github.com/fullmetalsonic/cotw-animal-outline/releases/latest)** · [English](README.md)

## 실행

1. ZIP을 원하는 폴더에 압축 풀고 `COTWAnimalOutline.exe`를 실행합니다. Python 설치나 게임 폴더로 파일 복사는 필요 없습니다.
2. 게임에서 싱글플레이 사냥터에 들어갑니다. 모드 창에서 필요한 기능을 켭니다. 프로그램 재실행 시 기본값은 모두 OFF입니다.
3. 맨 위 **전체 ON / 전체 OFF**로 여섯 기능을 함께 조작할 수 있습니다. **Ctrl+Shift+F10**은 하나라도 켜져 있으면 모두 끄고, 모두 꺼져 있으면 모두 켭니다. 단축키 충돌 시 버튼은 계속 사용할 수 있습니다.
4. 창을 닫으면 각 모드의 갱신을 중지하고 임시 후크를 복원합니다. 무기 소리는 OFF 후 새로 시작되는 소리부터 원래 것으로 돌아갑니다.

Windows **표시 언어**가 한국어면 한국어, 그 외에는 영어로 표시합니다. 국가·지역 설정과 무관하며 실행할 때 언어를 정합니다. 별도 영문 EXE는 필요 없습니다.

다른 드라이브, 공백·한글이 있는 설치 경로도 직접 지정할 필요가 없습니다. 게임 파일·세이브·Steam 실행 옵션을 편집하지 않습니다.

## v0.4.0 기능

| 기능 | 동작 |
|---|---|
| 생체 윤곽 | 흰색·파랑을 선택합니다. 새로 로드된 야생동물에도 적용하며 실제 탐지·정보 공개는 일으키지 않습니다. |
| 사체 윤곽 | 별도 색상과 ON/OFF. 기본색 주황 `#FF5900`. 장애물 뒤에서도 표시하며 아직 로드되지 않은 먼 모델은 강제로 생성하지 않습니다. |
| 닌자 | 플레이어·현재 ATV의 이동 소음과 모습에 대한 AI 감지를 차단합니다. 반려견 AI에도 같은 감지 차단을 적용합니다. 플레이어 효과음·소음계·냄새와 별도 발포 감지 경로는 유지합니다. |
| 반려견 윤곽 유지 | 전체 동물 흔적을 숨겨도 반려견의 원래 윤곽을 유지합니다. 게임의 사냥개 윤곽 ON·색상·가림 설정을 따릅니다. |
| 헬하운드 | 리트리버 회수 기능으로 1~9급 사체를 회수 대상으로 삼습니다. 1급은 기존 동작, 2~9급은 픽업 후 실제 사체를 플레이어 약 3m 앞에 옮깁니다. E로 일반 수확 화면을 열 수 있습니다. |
| 소음기 | 모든 무기의 발사음은 롱보우, 탄착음은 활 소리로 바꾸고 AI 발사·탄착 계산도 롱보우 프로필로 처리합니다. 탄도·피해·탄약·장전 소리는 유지합니다. |

각 기능은 독립 ON/OFF입니다. 활성 반려견·리트리버가 없으면 해당 기능은 연결을 기다립니다. 헬하운드는 DLC·회수 직업이 필요하며, 실제 등급·질량·트로피·보상을 편집하거나 자동 수확하지 않습니다. 자연스러운 입 물기·운반·투하 애니메이션은 제공하지 않습니다. 원래 이동·중량 계산을 유지합니다.

### 소음기 기준

- 실제 무기 137개: 소총 70, 권총 20, 엽총 28, 활·석궁 19개 자원 정의를 대조했습니다.
- 발사 소음 점수는 10m 이내 2이며 거리에 따라 감소해 75m에서 0이 됩니다. 탄착은 25m 이내 1이며 50m에서 0이 됩니다. 이 수치는 AI 계산 프로필이며 플레이어의 실제 가청 거리를 뜻하지 않습니다.
- 발사음 73개와 탄착음 12개를 바꾸고 이미 목표 소리인 13개는 그대로 통과합니다. 롱보우 원본의 한 재질 항목이 총 탄착음을 참조하는 예외는 활 탄착음으로 통일했습니다.
- **신규 소음기의 코드·자원·CPU 검사는 통과했으며 게임 내 실제 재생·청취는 아직 미확인입니다.** 원래 무기의 오디오 거리·파라미터 기본값은 유지하므로 모든 재질의 음량까지 원래 롱보우와 완전히 같다고 보증하지 않습니다.

## 지원 범위와 검증

- Windows 10/11 x64, Steam build **26051119**, game code **3366163**.
- 검증 대상 게임 EXE SHA-256: `33c8306e52c5541a5b87e4af576f4149f3da0c23b36775372ec6c41adbab73ca`. 다른 게임 버전은 동작을 중단합니다.
- 생체 흰색·파랑, 가려진 사체, 반려견 윤곽, 닌자 전환은 기존 사용자 확인과 기록을 재사용합니다. 헬하운드 E 회수는 2·3급에서 확인했으며 4~9급 실기는 미확인입니다.
- 소음기 AI는 실제 엔진 함수 바이트를 2,192개 조건에서 실행해 롱보우 계산과 대조했습니다. 여섯 기능의 64개 조합, 한·영 위젯/전체 토글, 단축키 등록·해제도 검사했습니다.
- 동물·사체 모델을 강제 스트리밍하지 않습니다. 전 종·전 맵·멀티플레이·장시간·다른 PC 실기는 검증 범위 밖입니다.
- 외부 객체 수명 경쟁을 완전히 제거하지 못했으며 동적 native SEH/unwind 등록은 구현하지 않았습니다.

정확한 PASS·미실행 범위는 [검증 기록](VALIDATION.ko.md)을 참조하세요. ZIP·EXE 해시는 Release의 `SHA256SUMS.txt`에서 확인할 수 있습니다.

## 업데이트와 소스 빌드

시작 시 비차단 확인과 수동 **업데이트 확인** 버튼을 제공합니다. 토큰 없이 최신 정식 Release와 SemVer를 비교하며 사전 릴리스·초안·단순 커밋은 제외합니다. 현재/최신 버전과 Release 링크를 표시하고 자동 다운로드·설치는 하지 않습니다. 네트워크 오류가 모드 사용을 막지 않습니다.

소스는 Python 3.12 x64와 Tkinter를 사용합니다. `build.ps1`은 프로젝트 가상환경과 고정 의존성으로 검사와 단일 EXE 빌드를 수행합니다.

```powershell
.\build.ps1
.\.build-venv\Scripts\python.exe -m unittest discover -v
.\.build-venv\Scripts\python.exe outline_mod.py --self-test
```

배포본은 게임 오디오·모델·FMOD DLL을 포함하지 않습니다. 필요한 런타임 고지는 `THIRD_PARTY_NOTICES.txt`에 있습니다.
